# はじめに

このコースでは、プログラミングがまったく初めての人に向けて、Rust という言語を使って基礎から学んでいきます。


## なぜRust？

このコースでは、プログラミング言語として Rust を使います。

Rust は「難しい言語」と言われることがありますが、このコースではむしろ**わかりやすい言語と主張します**。

Rust を採用した理由は次のとおりです。

* よく使われるようになってきている
* あいまいさがすくなく、理解しやすい
* trait という仕組みがあり、他の言語で見られる、class という仕組みよりわかりやすい
* 安全に動く


Rustは近年、さまざまな分野で使われるようになってきています。これから学ぶ言語として適しています。

trait という仕組みを使うことで、共通の性質をシンプルに表すことができます。複雑な仕組みに頼らずに考えることができます。

安全性が高く、エラーが起きにくいように設計されています。そのため、安心してプログラムを書くことができます。


## このコースでやること

このコースでは、次のような内容を順番に学びます。

* プログラムの基本的な考え方
* Rust の書き方
* 実際に動くコードを書く


## 進め方

最初から順番に進めていけば大丈夫です。

わからないところがあっても、いったん読み進めてみてください。
あとでつながるように作ってあります。
