## 情報には「種類」がある

例えば次の2つを見てください。

- 1  
- プログラミング  

この2つはどちらも情報ですが、性質が異なります。

- 1 → 数字  
- プログラミング → 文字列  

このように、情報にはそれぞれ「種類」があります。


## この「種類」を「型」と呼ぶ

プログラミングでは、この情報の種類を「型」と呼びます。


## 現実の情報で考える

例えば「人」という情報を分解して考えると：

- 名前 → 文字列  
- 年齢 → 数字  

これらの、「名前」や、「年齢」などの、複数の情報が集まったものと認識できます。

人という情報は、このような複数の情報の組み合わせで表すことができます。


## 構造体（struct）

### 複数の情報をまとめる仕組み

このような「複数の情報の組み合わせ」は、Rust では構造体で表現できます。


### 実際に Rust で書いてみよう

```rust
struct Person {
    name: String,
    age: Number,
}
```

> ※ ここでは説明を簡単にするため `Number` を使っています。後で説明しますが、実際の Rust では `i32` や `usize` などの型を使います。


### これは何を表しているか

このコードは次の意味です：

* `Person` という新しい型を作る
* `name` は文字列
* `age` は数値

> 人は「名前」と「年齢」を持つデータ構造である


### 書き方の意味

```rust
struct Person {
    name: String,
    age: Number,
}
```

* `struct Person {..}`
  新しい型 `Person` を定義する。詳しくは、`{..}` に書く

* `name: String`
  名前（文字列）

* `age: Number`
  年齢（数値）

  ---

  このように、「情報」は、色々な種類の情報の組み合わせでできています。

  新しく作った「型」をさらに組み合わせて、より複雑な情報の型を表すことが可能です。


## まとめ

* 情報には種類がある
* その種類を「型」と呼ぶ
* 複数の情報をまとめることができる
* Rust ではそれを `struct` で表す
