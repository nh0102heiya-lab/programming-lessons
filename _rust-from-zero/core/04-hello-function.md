これまでに、`main` という関数がプログラムの開始地点で、一番最初呼ばれる関数であることを学びました。

今回は一歩進んで、**自分で関数を作る**ことで、「関数とは何か」を理解していきます。


## 関数とは？

関数とは、**処理をひとまとめにしたもの**です。

たとえば、今まで書いていたコードはこうでしたね。

```rust
fn main() {
    println!("Hello, Rust!");
    println!("Welcome!");
}
````

このままでも動きますが、同じ処理をまとめて書くことができたら、プログラムが読みやすくなると思いませんか？

## 関数を作ってみる

「あいさつを表示する関数」を作ってみましょう。

```rust
fn greet() {
    println!("Hello, Rust!");
    println!("Welcome!");
}

fn main() {
    greet();
}
```

実行してみてください。

出力はこうなります：

```console
Hello, Rust!
Welcome!
```

## コードの意味

### `fn greet()`

```rust
fn greet() {
```

* `greet` という名前の関数を定義しています
* 名前は自由につけることができます

### 関数の中身

```rust
{
    println!("Hello, Rust!");
    println!("Welcome!");
}
```

* `{}` の中に、その関数の処理を書いています
* 今回は「2行のメッセージを表示する処理」を書きました

### `greet();`

```rust
greet();
```

* 関数を「呼び出す」書き方です
* 関数が呼び出されると、中に書いてある処理が実行されます（今回は、`greet` の中の処理が実行されます）

## なぜ関数を使うのか

関数を使うと、次のようなメリットがあります。

* 同じ処理を何度も書かなくてよくなる
* コードが読みやすくなる
* 処理を分けて考えられる

例えばこう書くこともできます：

```rust
fn greet() {
    println!("Hello!");
}

fn main() {
    greet();
    greet();
    greet();
}
```

```console
Hello!
Hello!
Hello!
```

1つの関数を何回も使えることが分かりますね。

## まとめ

この章では次のことを学びました。

* 関数は「処理のまとまり」
* `fn 名前()` で関数を作れる
* `関数名();` で呼び出せる
* 同じ処理を何度も使える
