前の記事では、情報には「型」があることを学びました。

ここでは、複数の型を組み合わせて、新しい型を作る方法を学びます。


## 構造体（struct）

### 複数の情報をまとめる仕組み

「人」のように、複数の情報の組み合わせで表せるものは、Rust では構造体で表現できます。


### 実際に Rust で書いてみよう

```rust
struct Person {
    name: String,
    age: Number,
}
```

> ※ ここでは説明を簡単にするため `Number` を使っています。後で説明しますが、実際の Rust では `i32` や `usize` などの型を使います。


### これは何を表しているか

このコードは次の意味です：

* `Person` という新しい型を作る
* `name` は文字列
* `age` は数値

> 人は「名前」と「年齢」を持つデータ構造である


### 書き方の意味

```rust
struct Person {
    name: String,
    age: Number,
}
```

* `struct Person {..}`
  新しい型 `Person` を定義する。詳しくは、`{..}` に書く

* `name: String`
  名前（文字列）

* `age: Number`
  年齢（数値）

  ---

  このように、「情報」は、色々な種類の情報の組み合わせでできています。

  新しく作った「型」をさらに組み合わせて、より複雑な情報の型を表すことが可能です。


## まとめ

* 複数の型を組み合わせて新しい型を作れる
* Rust ではそれを `struct` で表す
* `struct` を使うと、現実世界のものをデータで表現できる
