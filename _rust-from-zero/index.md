# Rust from Zero

この教材は、プログラミングをまったく知らない人を対象にした Rust 入門です。

最初はインストールを行わず、Rust Playground を使って学習します。

---

概念や Rust そのものの学習を行うCore編と、開発環境の構築を行うSetup編に分かれています。

内容はすべて「初学者向け」に設計されています。

学習者はCore編から始め、途中でSetup編に飛びます。環境構築は必要になるまでやらないような書き方としてますが、最初に行っても問題ありません。

現在製作途中で、Core編のいくつかの記事が公開されています。
Setup編は後に公開予定です。
